# dsh-pet 功能清单（给她核对用）

- 日期：2026-11-08
- 这份只列「要什么、不要什么」，一行一个；依据是 `dsh-pet-给roost设计.md` 的附录 33 条与 `dsh-pet-需求与验收.md`。
- 标「可选」的，要她点头才做。11-08 下午补的东西在最后。

## 一、要的

| # | 功能 | 一句话 |
| --- | --- | --- |
| 1 | 待机小动作 | 只留四样底噪：呼吸、张望、打盹、伸懒腰 |
| 2 | 走动/转向 | 默认原地，她让走才走，走完就停，不自己飘走 |
| 3 | 换动作节奏 | 两次自动换动作至少隔 3 分钟 |

| 5 | 拖拽甩抛 | 扔、摔、落地弹，不出屏幕、不卡缝 |
| 9 | 睡觉套 | 只在她真睡时演，睡着像睡着 |
| 14 | 工作状态 | 五档：思考、动手、等、出错、成了；不设「整理」 |
| 18 | 对话 | 走她那边，pet 自己的模型不生成任何字 |
| 20 | 话和动作联动 | 同一句的两半，从她一起出 |
| 23 | 右键菜单 | 设置、宠物包、隐藏、退出；没有「唤醒」 |
| 24 | 设置页 | 大小、位置、物理、开关、宠物包，加一条只读状态 |

| 27 | 桌面透明置顶窗 | 装进 DSH，不做 overlay、不做独立模式 |

## 四、11-08 下午补的三条（睡与醒）

1. 一轮没结束不算睡——回合还在跑（在想、翻长文件、调用卡住），多久没动静都算醒。
2. 停下来多久算睡可调，不是常数：默认 5 分钟，范围 1–60。
3. 睡着后只有她那边的动静能叫醒：回合开始、工具调用、她说话；余额、通知、日历、到点都不算。

判据：醒 = 回合进行中，或距最后一次动静不到「待睡分钟数」。
