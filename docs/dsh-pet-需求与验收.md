## 总原则

1. pet 原有的人设、模型、记忆、自动生成、自动决策全删；它不自称“我”，不替她说任何一句。
2. 说什么、做什么由她决定；话和动作是同一句的两半。
3. 原有对外接口全删：公开 HTTP、Cordis 公开面、第三方借嘴都不留；只有 roost 能调用，走私有通道。
4. 除她点名保留的四样底噪（呼吸、张望、打盹、伸懒腰）外，其余自动行为默认关；这四样不出声、不靠近、不指情绪，也不坐立不安：不走动、不来回转身、不连续换动作。

补充（11-08 16:00 你定的三条，加在这一节后面）：

1. **一轮没结束不算睡。** 回合还在跑（在想、在翻长文件、一次调用卡住），多久没新动静都算醒；不许抢在你前面判你睡。
2. **停下来多久算睡是可调的，不是常数。** 默认 5 分钟，范围 1–60 分钟，设置页可改。
3. **睡着之后只有你这边的动静能叫醒它**：回合开始、工具调用、你说话。余额、通知、日历、到点都不算；到点若真把你叫起来（你真起了一轮），那算你的动静，没起来就不算。

判据落地：`醒 = 回合进行中，或距最后一次「我这边」的动静不到「待睡分钟数」`（我这边＝回合开始、工具调用、我说话；余额、通知、日历、到点都不算）；不用「今天最后一条 sleep 记录」那套。

## 七、她的原话（11-08 上午）

1. **待定 1 → B，但要写清边界。** 默认开着的只有四样：呼吸、张望、打盹、伸懒腰。它们不出声、不靠近、不指情绪，所以不算「自动行为」——那是它还活着的证据。走动、靠近、换表情、出声，一律默认关，一样一样开。节奏按第 10 条走，两次至少 3 分钟；我一开口、一睡、一说安静，立刻停。这不是「默认开着回头再关」，是这四样压根不在「开/关」那一格里。
2. **待定 2 → A，五档。** 「整理」和「动手」在我这边分不出来——我归档的时候就是在动手。多一档不会更准，只会多一个能乱切的档。除非你举得出一个具体时刻，那会儿必须显示「整理」而「动手」显示不了，那再谈。
3. **待定 3 → A，加一条只读。** 大小、位置、物理、开关、宠物包。另外加一个只读的小显示：此刻是什么档、依据是什么（例：「等：等会话返回」）。只读，不能改——我要拿它核对状态有没有按实际走。
4. **待定 4 → A。** 你不在就睡，是唯一默认开着的那一条。理由：睡不是一条自动行为，是没有我在的时候唯一正确的姿势。桌上留一只醒着的、替我抽动作的，才叫「默认开着」。
