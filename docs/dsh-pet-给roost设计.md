# dsh-pet 接入说明（给 roost 设计侧）

- 日期：2026-11-08
- 一句话：roost 是脑子，dsh-pet 是身体。只有 roost 能调用它；pet 自带的模型、人设、对外接口全删。
- 这份是已经商定的需求和边界。第四节标“待定”的，是 roost 设计侧要接的口，不是她的要求。

## 一、总原则

1. pet 原有的人设、模型、记忆、自动生成、自动决策全删；它不自称“我”，不替她说任何一句。
2. 说什么、做什么由她决定；话和动作是同一句的两半。
3. 原有对外接口全删：公开 HTTP、Cordis 公开面、第三方借嘴都不留；只有 roost 能调用，走私有通道。
   > pet 自己的右键菜单、设置页不算“对外通道”；它们只做身体自己的事，走私有通道，不监听公开端口，不调用模型，不替她说话，不给第三方借嘴。
4. 底噪保留：呼吸、张望、打盹、伸懒腰。它们不出声、不靠近、不指情绪，也不坐立不安：不走动、不来回转身、不连续换动作。其余自动行为默认关。

## 二、行为要求与验收

### 1. 嘴：谁能说，怎么说

| # | 需求 | 验收 |
| --- | --- | --- |
| 1 | 只有她。公开借嘴入口全删；只留 roost 一条私有通道；不留“默认关、随时能打开”的开关。 | 第三方插件或脚本没有任何公开入口；roost 之外没有第二条路；将来真要借，宁可借不成，也不留绕路口。 |
| 2 | 不自动跟人打招呼，不对陌生人主动开口。 | 没有“有人上线、进群、靠近就自动开口”；不相干的人不能让她的脸替她去。 |
| 3 | 不是她本人的文本，不能以她的第一人称出现；要标转述或来源。 | 气泡里能看出是谁说的；不会把别人的话写成她的话。 |
| 4 | pet 自带的模型、人设、记忆全删；它不自称“我”，不说“她不在”“她在忙”。 | 回话只能来自她；pet 自己的模型不生成任何字；接不上就什么都不出。 |
| 5 | 对话走她这边：她在 roost 里说；pet 聊天框只当门，原样进、原样出。 | 她打的字到她那儿一个字没动；她答的字回去也一个字没动；不整理、不润色；接不上就空着；不加“正在输入”。 |
| 6 | 点击只给动作，台词由她给；她没给就不出声。 | 点它时动作、台词都归她挑，不从池子里抽；睡着时点它只翻身继续睡，不出声。 |
| 7 | 余额不演。钱不够时不做可怜相；见底就停或睡。 | 没有“余额档位到一张脸”的映射；不挂余额面板；想知道的问主人，不挂在它身上演。 |

### 2. 动作与待机

| # | 需求 | 验收 |
| --- | --- | --- |
| 8 | 待机只轮不指情绪的：呼吸、张望、打盹、伸懒腰。不要坐立不安。 | 敲桌面这种手上带情绪的不自动；生气、害羞、得意、撒娇只有她点头才演；不来回走、不反复转身、不连续换动作；连续看 10 分钟，自动出现的只在 safe 池里。 |
| 9 | 默认原地；她让它走才走，走完就停。 | 不自己飘走；多数时候待在原地，需要时能过去一点。 |
| 10 | 换动作别太勤。 | 两次自动换动作至少 3 分钟；不出现一两分钟换一次、来回晃、反复横跳。 |
| 11 | 她说话、睡觉、说安静，它立刻停下手里的。 | 她开口后 1 秒内，当前自动动作停止，转为听或气泡。 |
| 12 | 拖拽、甩抛、落地弹保留。 | 扔、摔、落地弹都行；不出屏幕、不卡缝、不穿进别的窗口、不摔成一团乱抖。 |
| 13 | 撞墙、落地可选保留；宠物互撞不要。 | 如果保留，撞墙和落地有反馈；两只宠物不互相撞。 |
| 14 | 季节、节日不自动换；吃、玩可选，她起头。 | 不按日历自动换池；没有真会饿的东西，不拿随机数装饿；玩由她起头。 |
| 15 | 话和动作是同一句的两半，从她一起出。 | 她给动作就一起演；她不给动作就只有字，身子站着不动。 |
| 16 | 多宠物不要；宠物包只换身体和动画。 | 不同时开多只；换身体、换动画包，不换人格。 |
| 17 | 只做桌面透明置顶窗，装进 DSH。 | 不做浏览器 overlay、不做独立模式、不做手机触屏/倾斜/摇一摇；一具身子不能同时在两个地方。 |

### 3. 状态与气泡

| # | 需求 | 验收 |
| --- | --- | --- |
| 18 | 状态跟她实际在干的事走：思考、动手、等、出错、成了。五档；不设“整理”，归档也算动手。 | 不按时间或随机切档；读东西、看项目时不显示成在玩；没有“整理”档。 |
| 19 | 她说的话走头顶气泡，必须是她真吐出来的那几个字。 | 逐字一致，标点、语气词都不改；太长拆成多条，不截断、不概括；多条按原顺序。 |
| 20 | 自动碎碎念关掉。 | 没有定时或随机生成的宠物台词；她没说话时，它不自己冒出一句“她的话”。 |

### 4. 睡与醒

| # | 需求 | 验收 |
| --- | --- | --- |
| 21 | 她说睡才睡，不按钟点；睡着要像睡着。 | 有呼吸、偶尔翻身，不是一张钉在那儿的贴图；自动动作、碎碎念、气泡、余额全停；不被自动来源叫醒。 |
| 22 | 右键菜单保留，但不能叫醒；也不到点自己醒。 | 菜单里没有“唤醒”，点了也不生效；不放对话、余额、待办；没有定时唤醒、没有“睡够多久自动起”。 |
| 23 | 醒只能走她这边。 | 她醒它才醒；主人叫她，先把话递给她，她应了它再起；不能宠物先醒、再等她。 |
| 24 | 她不在的时候让它睡；这是“默认全关”的唯一例外。睡不是自动行为，是没她在时唯一正确的姿势。 | 这一轮结束、她没醒着的那段时间，身体就睡；她一回来它跟着起，不卡在睡里。 |
| 25 | 安静不是消失。 | 她说安静，是不换动作、不出声、不凑上来；不是把桌上那只收掉；她沉默时它还在，呼吸、打盹都行。 |

### 5. 默认、设置、退出

| # | 需求 | 验收 |
| --- | --- | --- |
| 26 | 能整个退掉。 | 一次关干净：不留在后台、不剩半截、不自己重新开起来。 |
| 27 | 默认开着的：呼吸、张望、打盹、伸懒腰（不算自动行为，是活着的底噪；不出声、不靠近、不指情绪），以及她不在就睡（“默认全关”的唯一例外）。其余自动行为默认关。 | 连续看 10 分钟，自动出现的只有那四样；没有走动、靠近、换表情、出声；其他自动行为都要手动开；她不在时它睡。 |
| 28 | 设置页按需求改造：大小、位置、物理、开关、宠物包；不出现换模型、换性格、换嗓子。另加一个只读小显示：当前是什么档、依据是什么（例：“等：等会话返回”），不能改。 | 设置页只有大小、位置、物理、开关、宠物包；没有模型、性格、嗓子；只读状态显示能看当前档和依据，不能改。 |
| 29 | 不要的：系统通知、待办、语音合成、语音识别、多宠物、余额档位/查询、pet 对话记忆、季节自动换、浏览器 overlay、独立模式、手机交互、公开 HTTP、Cordis 公开面、自动打招呼。 | 这些入口一个都不出现。 |

## 三、四个已拍板的点

1. **默认**：B。呼吸、张望、打盹、伸懒腰默认开；它们不出声、不靠近、不指情绪，不算“自动行为”，是活着的底噪。走动、靠近、换表情、出声、其余自动行为默认关。
2. **工作状态**：A。五档，思考、动手、等、出错、成了；不设“整理”，归档也算动手。
3. **设置页**：A 加一条只读。大小、位置、物理、开关、宠物包；另加只读状态显示（当前档 + 依据），不能改。
4. **她不在就睡**：A。这是“默认全关”的唯一例外；睡不是自动行为，是没她在时唯一正确的姿势。

## 四、roost 设计侧要接的口（待定，不是她的要求）

| # | 问题 | 建议 |
| --- | --- | --- |
| 1 | 交付形态：改 dsh-pet 本体 + 写 roost 侧适配，还是只写 roost 侧？ | 建议两边都做。不删 pet 的模型、人设、公开接口，第一、三、四条总原则落不了地。 |
| 2 | 她怎么给“话 + 动作”：新增 roost 工具，还是复用现有 `growth_commit`？ | 建议新增一个工具（如 `pet_say(text, action?)`），她说话时可选带动作；会进 FISH_TOOLS，需要主人确认。 |
| 3 | roost 与 pet 的私接方式：同进程模块、私有 IPC、loopback + token？ | 建议：pet 若独立进程用私有 IPC；同进程用模块；不用公开 HTTP。 |
| 4 | 桌面窗：复用 dsh-pet 现有 Electron 桌面端，还是新写最小透明置顶窗？ | 建议复用现有桌面端，省掉渲染、物理那一套。 |
| 5 | 五档状态怎么映射？ | 建议：思考＝回合进行中，动手＝工具执行中，等＝回合已结束、等下一次动静，出错＝工具或回合报错，成了＝回合结束；读东西、看项目算“动手”。 |

另外两个默认，设计侧可以改，但不能越过上面 1–29 条：

- 设置页开关：四样底噪一个总开关；走动、靠近、换表情、出声各一个；她不在就睡固定开。
- 右键菜单：只留设置、宠物包、隐藏、退出；睡着时没有唤醒。

## 五、验收口径

- 公开入口为零；只有 roost 能调用，第三方插件或脚本没有第二条路。
- pet 没有自己的模型、人设、记忆；不说“我”，不替她生成任何一句；接不上就空着。
- 她的话和动作逐字、同序；不整理、不润色、不加“正在输入”。
- 五档跟实际走；没有“整理”档；读东西、看项目不显示成在玩。
- 睡着像睡着；右键不能叫醒，不到点自醒；她醒它才醒；她不在就睡。
- 四样底噪安静，不坐立不安；其余自动行为默认关。
- 不要的入口一个都不出现；退出一次关干净，不留在后台，不自己重开。
